# 页面规格（320×240 横向）

> 分辨率已由官方规格页核实为 320×240。以下尺寸为建议值，最终在 USART HMI 中按字库与控件实际尺寸调整。

## 页面 0：主页

- 顶部状态条：Wi-Fi 图标/状态、设备时间（约 24px 高）。
- 当前节气：大字（约 28px），右侧显示季节。
- 四个数据块 2×2：
  - 空气温度（°C）
  - 空气湿度（%）
  - 土壤湿度（%）
  - 光照（lx）
- 底部：适宜度分数 + 灌溉状态（运行/停止/故障）。
- 触摸：点击数据块进入环境页；点击节气进入节气页；点击泵状态进入灌溉页。

## 页面 1：二十四节气

- 当前节气名称、太阳黄经、季节。
- 简介 3–4 行（小字，避免溢出）。
- 农谚 1 条（滚动或分页）。
- 传统习俗 2 条。
- 农事建议 2 条。
- 底部：返回主页；上一节气/下一节气。

## 页面 2：环境监测

- 四项读数列表：名称、数值、单位、状态（在线/未标定/异常/过期）。
- 数据更新时间。
- 传感器状态：SHT31、BH1750、HW-390。
- 历史趋势：若屏幕资源允许，使用曲线控件；否则显示最近 5 个点或省略，并在文档标注。
- 不显示水位/剩余水量（硬件不存在）。

## 页面 3：智能灌溉

- 自动/手动模式切换。
- 水泵状态（运行/停止/故障）与本次运行秒数。
- 启动/停止按钮（触摸目标 ≥ 36×32）。
- 土壤湿度阈值、单次最长运行时间（只读展示；修改在设置页或 Web）。
- 最近 3 条灌溉记录。
- 安全提示：最长运行、间隔、传感器有效性由设备端执行。
- 不提供“按节气日期自动浇水”。

## 页面 4：系统设置

- 当前 Wi-Fi SSID、状态、IP。
- 扫描按钮、SSID 列表、密码输入（掩码）、连接按钮、连接状态。
- 重新配网入口。
- 设备名称、固件版本、土壤校准入口。
- 校准页：干燥/湿润原始值采集与保存；未完成时显示“未标定”。

## 视觉规范

- 配色：森林绿 `#173d32` / `#1d6049`，暖白 `#f7f5ed`，麦穗金 `#c69a48`。
- 背景不使用复杂渐变，保证 2.8 寸可读性。
- 重要数值字号 ≥ 24px；辅助文字 ≥ 12px。
- 图标使用 PNG 位图（24×24 或 32×32），不使用 Emoji。
- 页面切换保持单一导航路径，避免深层返回。
