# HMI 工程

## 状态

本目录**暂时没有** `.HMI` 工程文件。`.HMI` 是 USART HMI 上位机工程格式，本仓库无法用代码生成。

## 创建步骤

1. 安装淘晶驰 USART HMI 上位机（官方下载页）。
2. 新建工程，型号选择 `TJC3224T128_011R_A01`，确认分辨率 320×240、横向。
3. 导入或参考官方出厂工程：
   `http://filedown.tjc1688.com/tjcwiki/factory_project/T1/TJC3224T128.HMI`
4. 按 `../docs/PAGES.md` 建五个页面，按 `../docs/CONTROLS.md` 建控件与变量。
5. 生成中文字库，确认字库 ID 与控件绑定。
6. 编译工程，通过串口或 SD 卡下载到屏幕。
7. 联调 UART：按 `../../docs/UART_PROTOCOL.md` 与 `../../docs/TJC_ESP32S3_DEBUG.md` 验证帧与触摸事件。

## 注意

- `.HMI` 是工程文件，不是屏幕运行固件；不要把它描述为可直接运行的固件。
- 官方出厂工程可作为起点，但控件命名与页面布局仍需按本项目规格调整。
- 未确认的波特率、电平、字库 ID 不写入代码常量。
- 下载/编译失败时先检查型号、分辨率、字库与串口驱动，不要改设备端协议猜测。
