# Touch_screen

淘晶驰 TJC3224T128_011R_A01（2.8 英寸，320×240，电阻触摸）的页面规格、控件表与资源说明。

## 当前状态

- 已完成：官方资料核实、五页布局规格、控件/变量命名建议、UART 协议已核实部分。
- 未完成：`.HMI` 工程文件、字库、图标/背景资源、屏幕编译与下载。
- 本目录**不包含**可直接运行的屏幕固件；`.HMI` 需在 USART HMI 上位机中创建。

## 文件

- `docs/PAGES.md`：五个页面的布局与内容。
- `docs/CONTROLS.md`：控件、变量、触摸事件与设备字段映射。
- `HMI/README.md`：如何从官方出厂工程开始创建与下载。
- `assets/`：图标、背景、字库资源的规格与放置位置。

## 原则

1. 屏幕只展示状态、提交意图，不直接驱动 GPIO。
2. 中文必须生成字库；不使用 Emoji 代替图标。
3. 密码输入必须掩码显示，不在屏幕日志或页面明文回显。
4. 屏幕断线不能影响采集、自动灌溉与 Web。
5. 涉及水泵的触摸动作必须经过设备端安全校验与最长运行限制。
