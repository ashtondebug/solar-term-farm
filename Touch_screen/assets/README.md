# 屏幕资源

放置 USART HMI 工程使用的图标、背景与字库资源。

## 规格

- 背景：320×240 PNG，避免高频细节与大面积渐变。
- 图标：24×24 或 32×32 PNG，透明背景；风格统一，不使用 Emoji。
- 颜色：森林绿 `#173d32` / `#1d6049`，暖白 `#f7f5ed`，麦穗金 `#c69a48`。
- 中文字库：按 USART HMI 字库工具生成，记录字库 ID、字号与包含字符集。
- 命名：`icon_temp.png`、`icon_humidity.png`、`icon_soil.png`、`icon_light.png`、`icon_pump.png`、`icon_wifi.png`、`bg_home.png` 等。

## 状态

当前目录为空；资源需在制作 `.HMI` 工程时生成并放入。不要提交来源不明的版权素材。
