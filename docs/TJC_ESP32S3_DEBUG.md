# TJC 与 ESP32-S3 联调笔记

## 1. 接线

```text
ESP32-S3 GPIO17 (UART TX) ──► TJC RX
ESP32-S3 GPIO18 (UART RX) ◄── TJC TX
GND ──────────────────────── GND
TJC VCC ──► 按规格书供电
```

- 必须交叉 TX/RX；共地。
- 屏幕供电电压与 TTL 电平未核实；不要假定 5V 供电可以直接接 3.3V GPIO。
- 若使用电平转换，先确认方向与速率。

## 2. 参数

- 波特率：待按屏幕工程与 Wiki `QA/baudrate.html` 确认；代码中不得写死未核实值。
- 数据位/停止位/校验：待确认。
- `bkcmd`：默认 2（只返回错误）；联调时可临时调整，但量产配置需记录。

## 3. 调试步骤（待实现）

1. 只接屏幕与 ESP32，不接水泵。
2. 用 USB REPL 确认 UART 初始化成功；日志不得写到屏幕 UART。
3. 发送一条最小指令（页面切换或读取页面 ID），抓取屏幕返回。
4. 确认返回以 `FF FF FF` 结束；记录原始字节。
5. 触发一次触摸，确认 `0x65` 事件与控件 ID。
6. 断开/重连屏幕，确认设备不崩溃、Web/灌溉不受影响。
7. 最后再接入水泵，验证屏幕启动/停止仍受最长运行与故障保护。

## 4. 注意事项

- 不要把 `print()` 用作屏幕 UART 调试；会污染协议帧。
- 不要凭经验写命令字符串；先读官方指令集。
- 屏幕断线不能让主循环阻塞；发送队列要有上限。
- 屏幕只提交意图，设备端 `IrrigationController` 仍是唯一执行者。
