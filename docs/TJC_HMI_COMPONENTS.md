# TJC HMI 页面与控件规格

屏幕：TJC3224T128_011R_A01，320×240，横向，电阻触摸。以下为 320×240 的页面规划，具体控件属性与指令以 USART HMI 与官方 Wiki 为准。

## 1. 页面

| 页面 ID | 名称 | 主要内容 |
|---:|---|---|
| 0 | 主页 | 日期时间、当前节气、空气温度、空气湿度、土壤湿度、光照、适宜度、灌溉状态、Wi-Fi 状态 |
| 1 | 二十四节气 | 当前节气、简介、时间范围、太阳黄经、农谚、习俗、农事建议 |
| 2 | 环境监测 | 四项读数、更新时间、传感器状态、趋势（资源允许时） |
| 3 | 智能灌溉 | 自动/手动、泵状态、运行时间、阈值、灌溉记录、安全提示 |
| 4 | 系统设置 | Wi-Fi 扫描/SSID/密码、当前网络/IP、设备名称、校准、版本、重新配网 |

## 2. 控件与变量（命名建议）

> 变量名需按 USART HMI 的实际规则创建；以下只是设备端同步时使用的逻辑名，不能当作已核实的指令语法。

| 逻辑名 | 类型 | 说明 |
|---|---|---|
| `page` | 页面 | 当前页面 |
| `wifi_state` | 文本 | 已连接/连接中/配网中/失败 |
| `ip_text` | 文本 | 局域网 IP |
| `date_text` | 文本 | 设备本地日期时间 |
| `term_name` | 文本 | 当前节气 |
| `temp_value` | 数值 | 空气温度 °C |
| `hum_value` | 数值 | 空气湿度 % |
| `soil_value` | 数值 | 土壤湿度 % |
| `lux_value` | 数值 | 光照 lx |
| `score_value` | 数值 | 适宜度 0–100 |
| `pump_state` | 文本 | 运行/停止/故障 |
| `pump_mode` | 文本 | 自动/手动 |
| `run_seconds` | 数值 | 本次运行秒数 |
| `wifi_list` | 文本/列表 | 扫描结果 |
| `ssid_input` | 文本 | 用户输入 SSID |
| `pass_input` | 文本 | 密码输入（掩码显示） |

## 3. 触摸事件

- 主页/环境/节气：仅导航，无硬件动作。
- 灌溉页：启动/停止按钮、自动/手动切换、阈值调整；所有动作提交设备端校验。
- 设置页：扫描、选择 SSID、输入密码、连接、重新配网；密码不得明文显示。
- 屏幕不得直接控制 GPIO；只发送意图，等待设备状态回写。

## 4. 视觉

- 2.8 寸 320×240，信息密度必须克制；重要数据大字，辅助信息小字。
- 主色：森林绿、暖白、麦穗金；与 Web 管理页一致。
- 不使用 Emoji 代替图标；使用 PNG/位图资源。
- 中文需生成字库；字库 ID、字体大小在 USART HMI 中确认。
- 触摸目标不小于约 36×32 px（按实际控件调整）。

## 5. 交付方式

- 页面规格、控件表、变量表、图标与背景资源放在 `Touch_screen/`。
- `.HMI` 工程需在 USART HMI 上位机创建；官方出厂工程可作为起点。
- `.HMI` 不是屏幕运行固件；需编译/下载生成运行文件。
- 当前仓库尚未包含 `.HMI`，不得声称已完成屏幕工程。
