## 3. 传感器

| 传感器 | 接口 | 默认引脚 / 地址 | 状态 |
|---|---|---|---|
| HW-390 V2.0 土壤湿度 | ADC（AOUT） | GPIO4，ADC1 | 待开发板与探头实测 |
| SHT31 温湿度 | I²C | SDA=GPIO8，SCL=GPIO9，0x44 | 待总线扫描确认 |
| BH1750 光照 | I²C | 同总线，0x23 | 待总线扫描确认 |

- HW-390 已确认支持 3.3V 供电，AOUT 不超过 ESP32-S3 GPIO 允许范围；精确输出电压数值未提供，不做推测。
- 土壤湿度必须用干燥/湿润两点校准换算；当前驱动在未校准时返回 `uncalibrated`。
- SHT31 与 BH1750 共用 I²C 时需要确认上拉与地址冲突。
- **不安装水位传感器**；系统不提供水位、剩余水量或自动缺水检测。

## 4. 继电器与水泵

| 项 | 值 |
|---|---|
| 继电器 | 3.3V 供电、**高电平触发** |
| 控制引脚 | GPIO5 → 继电器 IN |
| HIGH（3.3V） | 吸合，水泵运行 |
| LOW（0V） | 释放，水泵停止 |
| 水泵回路 | COM / NO 常开触点；NC 不用 |
| 默认关闭 | IN 硬件下拉 + 继电器掉电释放 + 软件初始化 LOW |

未核对项：

- 继电器模块 IN 是否内部上拉（若上拉，外部下拉可能无效）。
- 继电器线圈电流与 3.3V 电源能力。
- 触点额定电流、直流感性负载能力。
- 水泵额定电压/电流、启动浪涌。
- 电源方案、保险丝、去耦、泵保护。

在完成以上核对前，不得把系统接到真实水泵上做长时间运行。

## 5. 板载 RGB LED

任务书要求使用板载 RGB LED 做状态指示，但**不得假定 GPIO48/38**。当前固件没有实现 LED 状态；需要按开发板原理图确认型号（WS2812 / 共阳 RGB / 其他）、GPIO 与驱动方式后再实现。

## 6. 电源

- 水泵与主控应使用独立供电或至少独立稳压支路，避免泵启动造成主控复位。
- 电池组额定电压不超过 12V；DC-DC、保险丝、开关、滤波按实物规格配置。
- 所有模块共地；继电器模块 VCC 按模块要求供电，不得从 GPIO 取电。
