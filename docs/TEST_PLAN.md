# 测试计划

## 1. 自动化测试（主机 CPython）

运行：

```bat
python -m unittest discover -s tests -v
```

覆盖范围：

| 文件 | 覆盖 |
|---|---|
| `test_config.py` | 默认配置、范围校验、校准成对、PIN 公开配置、深度合并 |
| `test_soil.py` | 两点校准、端点反转、钳位、未校准、ADC 越界 |
| `test_sht31.py` | CRC8、温湿度解码、有效帧、CRC 失败成对无效 |
| `test_suitability.py` | 全优、严重异常封顶、无效/过期不出分 |
| `test_irrigation.py` | 高电平极性、最长运行、MIN_OFF、自动触发/不触发、幂等、故障拒绝 |
| `test_solar_terms.py` | 2024 立春/春分/冬至、跨年 大寒、黄经范围、24 条 |
| `test_api.py` | envelope、PIN 401、配置 422、时间同步、坏 range、未知路由 |
| `test_web_parse.py` | 请求行、查询串 |
| `test_web_server.py` | CPython 上真实 HTTP socket 往返、静态 index |
| `test_history_store.py` | 追加/范围、坏尾行跳过 |
| `test_timeutil.py` | Unix 纪元、时区格式化 |
| `test_network.py` | 未配置、连接成功后才保存、密码不进状态、5 次失败转配网、取消恢复、扫描去重/排序 |

## 2. 模拟器端到端

```bat
python tools\devserver.py --port 8099
```

验证：

- `GET /api/v1/state` 返回 `meta.source=simulator`。
- `GET /api/v1/history?range=12h` 有点。
- `GET /api/v1/solar-terms` 返回 24 条。
- `GET /` 与 `/app.js` 200。
- 启动/停止控制返回 200，状态随设备反馈变化。
- 非法配置返回 422 envelope。
- 浏览器六页无「—」残留，模拟器横幅可见。

## 3. 真机手动清单（未执行）

### 电气与默认关闭

- [ ] 不接水泵，只接继电器；上电 IN 为 LOW。
- [ ] 复位/拔 USB/程序卡死时 IN 为 LOW、触点释放。
- [ ] 继电器模块 IN 内部上拉情况确认；必要时调整下拉。
- [ ] 水泵额定电流/浪涌与触点余量确认。

### 传感器

- [ ] SHT31 地址、CRC、温湿度合理。
- [ ] BH1750 地址、lux 随遮光变化。
- [ ] HW-390 干燥与湿润原始值，写入校准，百分比方向正确。
- [ ] 拔掉传感器后 UI 显示异常/未标定，自动灌溉不启动。

### 灌溉

- [ ] 手动启动，20 秒（或配置值）自动停止。
- [ ] 停止后 5 秒内不能再次启动。
- [ ] 自动模式在阈值以下启动，达到最长运行停止。
- [ ] 传感器过期时不自动启动。
- [ ] 页面显示与设备实际状态一致；刷新/重连后以设备为准。

### 网络与时间

- [ ] 首次配网（M3 完成后）与 5 次失败转配网。
- [ ] 断网后采集/自动灌溉继续，页面显示离线。
- [ ] 浏览器校时后节气正确；未校时显示「时间未同步」。

### TFT 与按钮

- [ ] TFT 上电常亮，竖屏显示空气温湿度、土壤、光照、水泵、适宜度和节气农事。
- [ ] 24 小时长时运行、故障注入、泵强制关闭与告警验收。
- [ ] 安装辅助触点后，验证反馈不一致会锁存故障并关泵。
- [ ] TFT 方向/刷新稳定性真机验收。
- [ ] TFT 在泵启动时的白屏/花屏电源与 EMI 整改验收。
- [ ] 按钮按一次启动，再按一次立即停止。
- [ ] 停泵后 5 秒内再按，启动排队到 `min_off_s` 后执行。
- [ ] 不按停止时，20 秒 `max_run` 仍会自动停止。
- [ ] 按钮不绕过最小停泵时间、故障锁存和最长运行时间。

## 4. 不覆盖

- 真实传感器精度与长期漂移。
- Wi-Fi 射频范围/干扰。
- 继电器与水泵的电气寿命、安规。
- TFT 长期老化、不同批次兼容性与背光电流。
- 浏览器兼容性矩阵（当前以 Chromium/Edge 验证）。
