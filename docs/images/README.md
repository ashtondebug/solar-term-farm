## 替换步骤

1. 将图片放到本目录，文件名与上表一致；
2. 在根目录 `README.md` 中找到对应的 `> **图片占位 ...**` 文字块；
3. 删除文字块，换成：

```markdown
![图片说明](docs/images/文件名.jpg)
```

图片建议不超过 1600px 宽；JPG/PNG 均可。不要提交包含 Wi-Fi 密码、PIN 或其他敏感信息的截图。
